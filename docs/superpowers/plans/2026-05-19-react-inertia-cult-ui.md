# React + Inertia.js + cult-ui Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate React + Inertia.js into the existing Laravel 13 + Livewire project and install cult-ui as the component library.

**Architecture:** Inertia.js will act as the bridge between Laravel (server-side routing/data) and React (client-side rendering). The existing Livewire pages remain untouched — Inertia/React pages run alongside them. New features will be built in React; the Livewire stack continues to serve existing pages.

**Tech Stack:** Laravel 13, Inertia.js 2.x, React 19, Vite, Tailwind CSS 3, shadcn/ui (base), cult-ui (component registry)

## Task 2: Install React + Inertia.js Client-Side

**Files:**
- Modify: `vite.config.js`
- Create: `resources/js/app.jsx`
- Create: `jsconfig.json`

- [ ] **Step 1: Install npm packages**

```bash
npm install @inertiajs/react react react-dom
npm install -D @vitejs/plugin-react
```

Expected: packages added, no peer-dep errors.

- [ ] **Step 2: Update vite.config.js**

Replace the entire content of `vite.config.js`:

```js
import { defineConfig } from 'vite';
import laravel from 'laravel-vite-plugin';
import react from '@vitejs/plugin-react';
import path from 'path';
import { fileURLToPath } from 'url';

const __dirname = path.dirname(fileURLToPath(import.meta.url));

export default defineConfig({
    plugins: [
        laravel({
            input: ['resources/css/app.css', 'resources/js/app.jsx'],
            refresh: true,
        }),
        react(),
    ],
    resolve: {
        alias: {
            '@': path.resolve(__dirname, 'resources/js'),
        },
    },
});
```

- [ ] **Step 3: Create the React entry point**

Create `resources/js/app.jsx`:

```jsx
import './bootstrap';
import { createInertiaApp } from '@inertiajs/react';
import { createRoot } from 'react-dom/client';

createInertiaApp({
    title: (title) => `${title} - Kamo`,
    resolve: (name) => {
        const pages = import.meta.glob('./Pages/**/*.jsx', { eager: true });
        return pages[`./Pages/${name}.jsx`];
    },
    setup({ el, App, props }) {
        createRoot(el).render(<App {...props} />);
    },
});
```

- [ ] **Step 4: Create jsconfig.json for path alias IDE support**

Create `jsconfig.json` in the laravel root:

```json
{
    "compilerOptions": {
        "baseUrl": ".",
        "paths": {
            "@/*": ["resources/js/*"]
        }
    }
}
```

- [ ] **Step 5: Update tailwind.config.js to include JSX files**

In `tailwind.config.js`, update the `content` array to include React files:

```js
content: [
    './vendor/laravel/framework/src/Illuminate/Pagination/resources/views/*.blade.php',
    './storage/framework/views/*.php',
    './resources/views/**/*.blade.php',
    './resources/js/**/*.{jsx,js}',
],
```

- [ ] **Step 6: Commit**


## Troubleshooting Reference

**"Module not found: @/"** — Check that `jsconfig.json` and `vite.config.js` both define `@` → `resources/js`.

**"tailwindcss-animate not found"** — Run `npm install tailwindcss-animate` and ensure the import is at the top of `tailwind.config.js`.

**Inertia renders blank page** — Confirm that the route uses `Inertia::render(...)` and the root view is `inertia` (set via `HandleInertiaRequests::$rootView`). The default is `'app'` — change it to `'inertia'` in the middleware file.

```php
// app/Http/Middleware/HandleInertiaRequests.php
protected $rootView = 'inertia';
```

**cult-ui component install fails** — Check that `components.json` exists and that the shadcn CLI can find your config. Run `npx shadcn doctor` to diagnose.

**Livewire still works** — Livewire and Inertia are completely independent. Existing Blade + Livewire routes are unaffected.
